# 🏦 Bank Management System

A simple **Bank Management System** developed using **Java**.

This project allows users to manage bank accounts and perform basic banking operations such as creating accounts, depositing money, withdrawing money, checking balances, and viewing account information.

---

## 📌 Features

### 👤 1. Create Account

Users can create a new bank account by entering their personal information.

The system stores:

* Account Number
* Customer Name
* Account Balance

---

### 💵 2. Deposit Money

Users can deposit money into their bank account.

The system automatically updates the account balance.

---

### 💸 3. Withdraw Money

Users can withdraw money from their account.

The system checks if the account has enough balance before completing the transaction.

---

### 💰 4. Check Balance

Users can check their current account balance.

---

### 📋 5. View Account Information

Users can view their account details, including:

* Account Number
* Customer Name
* Current Balance

---

### ❌ 6. Delete Account

Users can remove an existing bank account from the system.
